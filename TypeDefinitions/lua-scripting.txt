GetAITarget
Returns a target from the Creature's threat list based on the supplied arguments. 
 enum SelectAggroTarget
{
 SELECT_TARGET_RANDOM = 0, //Just selects a random target
 SELECT_TARGET_TOPAGGRO, //Selects targets from top aggro to bottom
 SELECT_TARGET_BOTTOMAGGRO, //Selects targets from bottom aggro to top
 SELECT_TARGET_NEAREST,
 SELECT_TARGET_FARTHEST
};
 
 For example, if you wanted to select the third-farthest Player within 500 units that has a knockback immunity buff (Ability group ID 708), you could use this function like so: 
 target = creature:GetAITarget(SelectAggroTarget.SELECT_TARGET_FARTHEST, true, 3, 500, 708)

GetCurrentAAO
Fetches the current Against All Odds (AAO) value for the region the creature is in. 
 A positive value means Destruction is the underdog , and a negative value means Order is the underdog . 
 ⚠️ Note: The value is divided by 20 compared to what players see in the UI. 
To get the actual AAO percentage shown to players, multiply the result by 20. 
 Example: 
 
 3 → 60% AAO bonus for Destruction 
 -2 → 40% AAO bonus for Order 
 0 → No AAO bonus (balanced) 
 
 
 Synopsis 
 aao = Creature:GetCurrentAAO()
 
 
 Arguments 
 None 
 
 Returns 
 
 
 
 Value 
 Type 
 Description 
 
 
 
 
 aao 
 int 
 Scaled AAO value. Positive = Destruction underdog, Negative = Order underdog. Multiply by 20 for % shown to players.

RvR Events
Used to trigger custom scripted events during the RvR campaign — like King of the Hill, supply events, or zone-specific skirmishes. 
 
 How It Works 
 To create a new RvR event, you need: 
 
 A Creature entry that acts as the event controller (invisible or visible) 
 A Lua script tied to that unit 
 An entry in the battlefront_events database table 
 
 The event will automatically be triggered based on how it's configured in the table. 
 
 Required Lua Functions 
 Your Creature script should include: 
 
 
 
 Function 
 Purpose 
 
 
 
 
 Creature:WinOMeterSend(orderPoints, destroPoints) 
 Sends live score updates to players near the event 
 
 
 Creature:RemovePlayerFromEvent(player) 
 Removes a player from the event if they leave the area, die, etc. Cleans up their UI 
 
 
 Creature:EndRvREvent() 
 Ends the event and removes it from the active campaign 
 
 
 
 Your script should also: 
 
 Track event score/state 
 Handle reward distribution when the event ends 
 
 
 battlefront_events Table Structure 
 This table defines when, where, and how the RvR event spawns.

CastAbility
Makes the Unit cast the ability on the target, similar to an ability cast by a player. Cast requirement checks can cause this to fail (see information below), check the return value to see if it was successful. Can be used to cast abilities outside of the Unit's AbilitySet, and any in-progress cast or channel will be cancelled. 
 Casting Requirement Checks 
 
 
 
 Requirement 
 Note 
 
 
 
 
 Ability Cooldown 
 CastAbility will fail if the ability is on cooldown 
 
 
 Global Cooldown 
 CastAbility will fail if the unit is in GCD and the ability is not IgnoreGCD 
 
 
 Casting Requirements 
 CastAbility will fail if the current target does not meet cast requirements: Morale level for morale abilities, level requirements, usable in stealth, line of sight, weapon requirements, etc 
 
 
 Target 
 CastAbility will fail if the current target does not match the ability target type 
 
 
 Ability Requirements 
 CastAbility will fail if any of the ability requirements are not met 
 
 
 Casting Requirements 2 
 CastAbility will fail if the caster is out of AP, moving and not an instant or MoveCast ability, too close or out of range, out of cone of fire 
 
 
 
 It is recommended to use CastAbility when the ability has VFX associated with it, or a projectile or similar. Using AddAbility bypasses the ability casting system entirely, so will ignore any cast time, projectile VFX, etc.

Returns a runtime-persistent cache tied to the WorldObject. This data will remain for as long as the WorldObject exists, or until a server restart. Any data set on a non-player Unit will be cleared when the Unit respawns. 
 A reload of the Lua state will NOT clear this cache. 
 This cache can be added to and read from with the following sub-methods. 
 -- Sets the key-value pair in the cache
WorldObject:Data():Set("key", val)

local val = WorldObject:Data():Get("key")

-- Removes the key-value pair from the cache

-- Returns all the key-value pairs as a Lua table indexed by the keys

Adds coroutine execution support to creatures, game objects, and scripts, allowing Lua functions to be paused and resumed over multiple frames or after timed delays. 
 Synopsis

 Arguments

 The coroutine function must accept the correct number of arguments being passed to it (the object itself and any additional ones). If this is not correct, it will fail silently.

 Notes 
 
 Coroutines allow multi-step scripted behaviour without blocking the game loop. 
 If delayMs is provided to coroutine.yield , the coroutine resumes after that many milliseconds. 
 If delayMs is omitted, the coroutine resumes on the next frame. 
 If the owning object is destroyed or despawned, the coroutine stops automatically. 
 Multiple coroutines can run on the same object simultaneously. 
 
 Example 
 local function GuardDialogue(creature, player)
 creature:SetWeaponStance(WeaponStance.MELEE)

 coroutine.yield(1000) -- wait 1 second

 creature:Say("Stand back! Or I'll have you arrested!")

 coroutine.yield(5000) -- wait 5 seconds

 creature:SetWeaponStance(WeaponStance.SHEATHED)

 coroutine.yield(2000) -- wait 2 seconds

 creature:Say("That's right " .. player:GetName() .. "you little git!")

 coroutine.yield(5000)
 creature:Say("Frame")
 coroutine.yield() -- next frame
 creature:Say("Frame")
 coroutine.yield()
 creature:Say("Frame")
end

local function OnInteract(creature, player)
 creature:StartCoroutine(GuardDialogue, player)
end

RegisterCreatureScript(898, CreatureScript.OnInteract, OnInteract)

ToCreature
Attempts to convert the WorldObject to a Creature. 
 If the WorldObject is not a Creature, returns nil . 
 Synopsis 
 creature = WorldObject:ToCreature()
 
 Arguments 
 None. 
 Returns 
 
 
 
 Value 
 Type 
 Note 
 
 
 
 
 creature 
 Creature 
 The WorldObject as a Creature, or nil .
